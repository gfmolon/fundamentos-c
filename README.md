# Fundamentos em C

Repositório com exercícios e estudos em linguagem C, desenvolvidos durante a graduação em Análise e Desenvolvimento de Sistemas na UCS.

## Conteúdos

- Lógica de programação
- Funções
- Structs
- Manipulação de arquivos texto
- Arquivos binários
- Ponteiros
- Vetores e matrizes
- Ordenação

## Objetivo

Consolidar fundamentos importantes de programação, organização de dados, memória e resolução de problemas usando a linguagem C.
